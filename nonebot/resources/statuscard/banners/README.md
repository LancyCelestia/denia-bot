# 集群卡 / 报表横幅素材

集群卡、日报和周报每次排版时从这里随机取一张作为顶部横幅（`status_image.banner_art`）。
状态卡主视觉固定使用上一级的 `denia-bubbles.jpg`；那张也会作为本目录为空时的兜底一起参与随机。

| 文件 | 尺寸 | 来源 |
|---|---|---|
| `denia-starlight.jpg` | 1600 × 667 | <https://www.hdbz.net/wallpaper/202606/202750.html>（原图 3840 × 1600，站点提供 1600 px 宽版本） |
| `denia-moonlight.jpg` | 1600 × 667 | <https://www.hdbz.net/wallpaper/202606/202751.html>（同上） |

- 角色与美术权利归其权利人；这些图片不适用仓库的代码许可证，仅用于本机渲染的个人机器人卡片。
- 来源为壁纸聚合站（高清壁纸网），尚未核对首发出处；需要替换或删除时直接改本目录，重启机器人即可。
- 按 1600 px 宽保存，渲染时再缩到 1430 px 宽显示；不要放小于 1430 px 宽的图，否则会被放大发虚。
- 新增图片：`jpg / jpeg / png / webp` 放进本目录就会自动参与随机，不需要改代码；损坏的文件会被跳过。
