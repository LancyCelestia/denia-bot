# 表情包核心功能实施计划

目标：在现有 NoneBot + MuiceBot 项目中实现手动管理表情包、按会话控制及聊天时由主模型选择分类发送图片。

- `nonebot/meme_logic.py`：持久化分类、图片和会话规则；实现流式标记解析。
- `nonebot/plugins/meme.py`：向模型提供分类并处理流式和非流式回复，使用图片字节发送。
- `nonebot/dashboard.py`、`nonebot/dashboard.html`：复用既有认证，提供管理和上传界面。
- 测试：覆盖分类管理、上传校验、会话规则、标记拆分及钩子集成、认证；确认相关回归测试。

默认空图库不影响聊天；图片语义检索、自动收集、资源广场和云同步不属于本次范围。不得改变既有限流、模型切换和人格设置。
