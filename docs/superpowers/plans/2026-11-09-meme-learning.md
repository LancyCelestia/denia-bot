# 表情包学习实施计划

目标：主人私聊启停学习模式，发送图片后自动视觉识别、分类、生成向量；正常聊天发送时按语义选图。

- 仅按已有主人 QQ 身份配置授权私聊；学习模式下收到的图片进入持久队列，停用后不再接收新图，已接收任务继续完成。
- 原图先落入 SQLite 队列，按图片内容去重；后台识别失败保留图片和失败状态，可查询和重试。
- 视觉模型产生分类、含义与使用场景，调用现有 Embedding 服务生成向量；数据与原图库共享，旧数据兼容。
- 机器人决定使用某分类后，按本轮聊天语义挑选该分类中已向量化的图片；无可用向量或服务异常时回退原有随机选图。
- QQ 图片段优先支持；特殊表情类型按协议端提供的可取回图片处理，不可取回时明确报告失败。
- 覆盖权限、队列去重与重试、并发与关闭、视觉及向量异常、语义选图和已有聊天链路；保留线上数据并进行服务器隔离验收。
